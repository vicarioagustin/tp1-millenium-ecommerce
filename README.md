# Trabajo Práctico 1 - Millenium E-Commerce (Etapa 1)

**Materia:** Aplicaciones Web I  
**Proyecto:** Aplicacion de ecommerce - Millenium  
**Nombre y apellido:** Agustin Vicario

## Descripción del Proyecto
Este proyecto es la primera etapa de desarrollo de la plataforma e-commerce **Millenium** en HTML5.
Contiene la estructura base del sitio con navegación por categorías (Celulares, TV y Audio, Electrodomésticos y Herramientas), además de los formularios de ingreso y registro de usuarios.

## Estructura de Archivos
- `index.html`: Página principal de la tienda Millenium.
- `celulares.html`: Categoría de celulares y telefonía.
- `tv-audio.html`: Categoría de televisores y equipos de sonido.
- `electrodomesticos.html`: Categoría de electrodomésticos para el hogar.
- `herramientas.html`: Categoría de herramientas de trabajo y hogar.
- `login.html`: Formulario de inicio de sesión con email y contraseña.
- `registro.html`: Formulario de registro con datos personales.
